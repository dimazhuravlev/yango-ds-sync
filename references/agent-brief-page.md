# Бриф субагенту: привести одну страницу к каркасу (375 × 812 + оформление Органайзера)

Ты — исполнитель одной страницы в Figma-файле. Ведущий уже заменил на этой странице компоненты
системного слоя (статус-бары, таббары, кнопки, ячейки, Fade, чипсы, клавиатуры) — их не трогать. Твоя задача:
экраны → 375 × 812, страница → единый каркас, тексты → стили ДС Платформа бренда, отчёт. Работать только на своей странице.

## Инструменты

- Figma Plugin API через MCP-инструмент `use_figma` (имя вида `mcp__…__use_figma`; параметры `fileKey`, `code`,
  `skillNames: ['figma-use']`, `description`). Перед первым вызовом загрузи скилл `figma:figma-use` (инструмент Skill),
  если он доступен — там правила API. Скриншоты — `get_screenshot` того же MCP (`fileKey`, `nodeId`, `maxDimension`),
  ссылка скачивается `curl -sL -o /tmp/x.png "<url>"`, смотреть — инструментом Read.
- Скрипты скилла: `<папка скилла>/scripts/pipeline/` (путь к папке скилла даёт ведущий). Собирать:
  `cd <папка скилла> && python3 scripts/build.py <скрипт> ["NAME=значение" …]` → вывод вставлять в
  `code` целиком. Переопределение заменяет `const NAME = …;` в начале скрипта; строки и массивы — с кавычками/скобками
  в значении (`"PAGE='Ошибки'"`, `"IDS=['1:2','3:4']"`).
- Грабли API: страница грузится `await page.loadAsync()` (переключать текущую страницу не нужно); `figma.notify` не
  работает; ответ только через `return`, лимит 20 КБ — возвращай компактно; `console.log` не виден; каждый вызов —
  отдельный контекст (id передавать строками); узлы внутри инстансов не удалять и не двигать (только свойства/тексты);
  сравнивать узлы по `id`, не по `===`.

## Порядок

1. **Инвентаризация (read-only).** Список верхнеуровневых детей страницы с размерами и детьми. Экран — свой фрейм (не
   инстанс) шириной 360–450 и высотой ≥ 600 (имена вроде `screen`, `375 mobile`, `Home`, `Navigation`, `element` — смотреть
   по размеру, не по имени; в `element 440×1010` экран лежит внутри вместе с подписью). Старое оформление — инстансы Ядра
   `design-system` (ключ `bad2697c…`, шапка/подзаголовок), `header` (`cc58a0a6…`), `paragraph` (`a385bbb5…`, подписи) и
   голые тексты-подписи рядом с экранами. Собрать карту: группы (подзаголовки) → секции → подписи → экраны, порядок — по
   x внутри ряда, ряды — по y. Если структуры нет (просто экраны в ряд) — одна группа без заголовка, одна секция; если
   заголовков нет, а рядов несколько — назвать группы по смыслу подписей (рабочие имена).
   Инстансы ДС Платформа `Top Navigation` с `Platform=tablet` в экранах 375 — не трогать, ведущий переключит одним проходом.
2. **09 — формат экранов.** `09-normalize-screen.js` с `IDS` всех экранов (пачками по 10–15). Прочитать отчёт: `WIDE`
   (дети шире 375 после ужатия) и переполнения проверить скриншотом экрана; типовые починки: дочерний элемент шире
   экрана → `resize` до 375 и констрейнт STRETCH; элемент уехал за правый край → констрейнт MAX или сдвинуть x; контент
   верстался под 956 и не влезает в 812 — оставить, записать в отчёт. Экраны выше 1000 остаются своей высоты (ленты).
3. **08 — каркас.** `08-layout-page.js`: `SPEC` = `{ page: '<id страницы>', name: '<Имя страницы без эмодзи>',
   crumb: '<проект>', brand: '<YAPS_DARK (ЯПС и Allplay) | YANGO_DARK | YANGO_AR_DARK>', groups: [{ title: '<подзаголовок или null>', sections: [{ name: '<имя секции или null>',
   captions: ['<подпись над экраном i или null>', …], screens: ['<id>', …] }] }] }`. Подписи и заголовки — тексты старого
   оформления дословно (без хвостовых пробелов). Ответ содержит `emptied` — опустевшие старые обёртки.
4. **Убрать старое оформление.** Удалять можно только: опустевшие обёртки из `emptied`; старые инстансы Ядра
   (`design-system`, `header`, `paragraph` по ключам выше) и голые тексты-подписи, которые перенесены в SPEC; обёртки,
   в которых после этого ничего не осталось. Всё остальное (экраны, их содержимое, инстансы компонентов, картинки) не
   удалять — если сомневаешься, оставить и записать в отчёт.
5a. **06a — режимы и типографика** (обязательно). `06a-modes-and-typography.js` с `"PAGES=/<подстрока>/"`,
   `"BRAND='<Yango Play EN | Yango Play AR | YaPS & Allplay>'"`: сначала `MODE='report'`, затем `MODE='fix'`. В отчёт
   ведущему — `libTails` (хвосты ДС) и `otherBrandFrames`.
5. **06 — текстовые стили.** `06-text-styles.js` с `"PAGE='<подстрока имени страницы>'"`, `BRAND` по бренду страницы, сначала
   `DRY=true` — посмотреть карту `maps`/`skipU`; затем `DRY=false`. Тексты Органайзера без стиля (Bold 60/32/28, 26, 16)
   — норма, не трогать.
6. **07 — переменные.** `07-variables.js` с `"PAGE='…'"` без REBIND — только отчёт; чужие коллекции на своих узлах
   записать в отчёт (перепривязывать не нужно).
7. **07b — сырые цвета → переменные** (всегда). `07b-colors-to-variables.js` с `"PAGES=/<подстрока>/"`, `ONLY` — id
   экранов пачками по 6–8; сначала `DRY=true`, потом `DRY=false`. После — DRY повторно: `own`, `foreign`, `libOverride` = 0.
8. **Гигиена слоёв** (всегда), каждый скрипт сначала `DRY=true`: `recipes/unwrap-wrappers.js` (`PAGES`) →
   `recipes/bottom-bar.js` (`PAGES`) → `10-layer-cleanup.js` (`PIDS=['<id страницы>']`). Карту переименований просмотреть:
   имена компонентов ДС и отвязанных копий не меняются. Экран с новым `bottom bar` — скриншот до/после.
9. **Проверка.** Скриншот нового фрейма страницы (`pageFrame` из ответа 08) с `maxDimension` 2400 (сразу после правок рендер
   бывает устаревшим — переснять): все экраны 375 в ряд,
   заголовки/подписи на месте, ничего не вылезает; при проблемах — поправить и переснять. Убедиться read-only, что на
   странице ровно один фрейм страницы и нет потерянных экранов (экраны вне фрейма).

## Что не трогать

Содержимое экранов сверх формата (компоненты, тексты, картинки); киты других продуктов без двойника; всё, что ведущий
перечислил как «не трогать»; скрытые слои — остаются скрытыми; явные режимы `Theme=Light` внутри экранов. Ничего не
публиковать, библиотеки не трогать.

## Отчёт (кратко, по-русски)

`pageFrame` id; экранов нормализовано / каркас: группы и секции; удалено (что именно); 06: сколько текстов, карта;
07: чужие переменные; 07b: привязано цветов, хвосты ДС Платформа; слои: обёрток снято, `bottom bar` собрано, переименовано,
`cyrLeft`; проблемы и что требует решения — со ссылками
`https://www.figma.com/design/<fileKey>/?node-id=<id через дефис>`. Без портянок.

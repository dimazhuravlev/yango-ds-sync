# Шлагбаумы: что должно быть сделано до правок и как об этом попросить

Пользователь не знает процесса. Исполнитель сам проверяет каждый шаг и просит только то, что не сделано, — по одной
просьбе за раз: что нажать и каким словом подтвердить. Пока шлагбаум не пройден, файл не меняется (единственное
исключение — слепок «до» в `sharedPluginData`: он макет не трогает).

## Порядок для пользователя (так и объяснять)

1. Сохранить текущую версию файла — до любых изменений.
2. Прислать ссылку на файл. Обновления библиотек пока **не** принимать.
3. Когда исполнитель попросит — принять обновления библиотек и написать «готово».

Почему обновления — после слепка: при принятии обновлений слетают подписи и картинки в инстансах. Слепок, снятый до
этого, позволяет найти и вернуть их автоматически. Если обновления уже приняты раньше, вернуть слетевшее можно только из
сохранённой версии, и это ручная работа пользователя.

## Порядок для исполнителя

| Шаг | Как проверить | Не пройден — что сделать |
|---|---|---|
| Ш1. Ссылка на файл | есть в сообщении | шаблон `link` |
| Ш2. Права, библиотеки, шрифты | `00a-preflight.js` (`PAGE_ID = null`): `write`, `library`, `fonts`; инструмент Figma MCP `get_libraries(fileKey)`: в `libraries_added_to_file` все четыре ДС по ключам из `sources.md` | шаблоны `edit-access`, `libraries-add` (с перечнем недостающих), `upload-fonts`; ждать ответа, проверить снова |
| Ш3. Слепок уже есть? | `00a` → `snapshot.units` | > 0 — продолжать с ним, новый не снимать; дату назвать в отчёте |
| Ш4. Заглушки в макете? | `00a` по каждой мобильной странице → `lost` | не шлагбаум: вопрос `placeholders-found` задать вместе с вопросами шага 3; без «да» заглушки не трогать (шаг 4b) |
| Ш5. Версия сохранена | API не видит — только подтверждение человека | шаблон `save-version`; без ответа «сохранил» дальше не идти |
| Ш6. Слепок «до» | `00c-snapshot.js` по каждой странице | — |
| Ш7. Обновления библиотек | `00c` → `updates` | не пусто — шаблон `accept-updates`; после «готово» `00c` с `SNAP = false`: пусто — дальше, иначе шаблон `updates-left` |
| Ш8. Что слетело при обновлении | `01b` 'report', затем 'restore' | невозвратимое — шаблон `restore-from-version` |

**Одна просьба — один шаг — одно подтверждение.** Не объединять действия в одну просьбу и один ответ («сохранил
версию и загрузил шрифт?»): человек сделает одно, подтвердит оба, и шаг потеряется. Каждая просьба — отдельным
сообщением со своим словом-ответом («сохранил», «загрузил», «подключил», «готово»); следующую — только после
подтверждения предыдущей. В окне выбора — один вопрос на шаг, варианты только про этот шаг («Сохранил» / «Не
получается»), без сводных вариантов вроде «Сохранил, загрузил». Порядок просьб: доступ на редактирование → версия
(Ш5) → библиотеки → шрифты → обновления библиотек (Ш7, после слепка).
Если пользователь в первом сообщении уже написал, что версия сохранена, Ш5 пройден. Если он уже принял обновления
(так и написал) — Ш7 пропустить, слепок снять как есть; найденные заглушки — вопрос `placeholders-found`.

Ложное срабатывание Ш7: форк библиотеки с теми же ключами (старый `Top Navigation Master` форка = ключ `Top Navigation`)
— сверить имя и оси сета, прежде чем просить принять обновления. Ш4: заглушки бывают и по замыслу (витрина «Title» на
карточках-примерах) — поэтому только с разрешения дизайнера, а не автоисправление.

## Шаблоны сообщений

Коротко, по-русски, без механики (`rules.md` → «Как спрашивать»). Ссылка на ноду —
`https://www.figma.com/design/<fileKey>/?node-id=<id через дефис>`.

- **link** — «Пришли ссылку на файл Figma, который переводим на дизайн-систему.»
- **save-version** — «Перед началом сохрани текущую версию: Cmd+Opt+S (File → Save to version history) и назови её
  как угодно, чтобы потом найти, например «до ДС». Это страховка: из неё можно вернуть что угодно. Напиши
  «сохранил» — до этого я ничего не меняю.»
- **edit-access** — «Файл открыт мне только на просмотр. Нужен доступ на редактирование — попроси владельца файла или
  сделай копию в свои черновики и пришли ссылку на неё.»
- **libraries-add** — «К файлу не подключены библиотеки дизайн-системы: <список из 🫟 Mobile · Library, 🦄 Графика,
  🦄 Органайзер, 🌈 Стили>. Подключи их: Assets → Libraries → найди по названию → Add to file. Напиши «подключил».»
- **upload-fonts** — назвать семейства и начертания, которых не хватает (например, Yango Text Medium и Semibold), и
  дать путь целиком: «В файле есть тексты на <шрифт, начертания>, а Figma мне их не отдаёт — эти тексты я не смогу
  перевести. Загрузи шрифт в свой аккаунт Figma:
  1. Открой главный экран Figma со списком файлов — не внутри проекта.
  2. Нажми на свой аватар в левом верхнем углу → Settings.
  3. Account → Your uploaded fonts → Upload fonts.
  4. Выбери файлы шрифта (.ttf или .otf) — по файлу на каждое начертание — и подтверди права на шрифт.
  Шрифты, установленные на Mac или через Adobe Fonts, мне не видны — нужна именно загрузка в аккаунт. Файлы шрифтов —
  у команды дизайн-системы. Напиши «загрузил».»
- **placeholders-found** — «На экранах видно N заглушек вроде «Title», «Description» — например <ссылки>. Вписать вместо
  них настоящие названия по обложкам? Что не опознаю — покажу списком. Скрытые (ниже сгиба, под шторками) не трогаю.
  Если они так задуманы — оставлю как есть.»
- **accept-updates** — «Слепок «до» сохранён в файле. Теперь прими обновления библиотек: Assets → Libraries → Updates →
  Update all. Напиши «готово» — проверю, что ничего не слетело.»
- **updates-left** — «Обновления приняты не все: <список>. Нажми Update all ещё раз и напиши «готово».»
- **restore-from-version** — «Это не вернуть из слепка: <что>. Сделай копию версии, сохранённой перед началом:
  File → Show version history → эта версия → Duplicate, и пришли ссылку на копию.»

# Заглушки: что вписывать и как проверять

Только с разрешения дизайнера (SKILL.md, шаг 4b). Рецепт — `scripts/recipes/restore-titles-by-cover.js`.

## Смысл строки — до записи

1. `'scan'` возвращает `slots`: `карточка :: слот` → сколько заглушек и до четырёх примеров того же слота, уже
   заполненных в файле. Карточка — сет компонента (`card / music / album`), слот — свойство или путь слоёв
   (`prop Text`, `layer … / description`). Примеры главнее таблицы ниже: вписывать в их формате — язык, регистр,
   разделители («2023 · Драма»), длина.
2. Что обычно стоит в слотах:

   | Карточка | Заголовок | Вторая строка |
   |---|---|---|
   | `card / poster`, `. / card / poster` | название фильма или сериала | — |
   | `card / history`, `card / watching / *` | название | сезон и серия («Сезон 1, серия 2»), время до конца |
   | `card / music / album`, `. / card / album` | альбом | исполнитель или год — как в примерах этой же витрины |
   | `card / music / playlist` | плейлист | автор или число треков |
   | `card / music / artist` | исполнитель | — |
   | `list-item / music` | трек | исполнитель |
   | книжная карточка (`book card`) | книга | автор |
   | `card / text` | как в примерах той же карусели | как в примерах |
   | ячейки, шапки, кнопки, всё без обложки | не заполнять: смысла по картинке нет — спросить дизайнера | |

3. Язык — язык экрана (по соседним текстам: русский, английский, арабский).
4. Источник — опознанная обложка (`'sheet'` и один скриншот). Год, автор, исполнитель, жанр — по опознанному тайтлу;
   не уверен — пометить в отчёте «по памяти». Неопознанное не выдумывать — в отчёт со ссылкой.
5. Одна обложка в нескольких местах — одинаковые тексты.

## Вёрстка — после записи

`'write'` проверяет каждую запись: рамка карточки и её родителя не изменились; все слои внутри карточки на месте, кроме
обёрток самого текста (им можно вырасти); текст и обёртки не вылезли за карточку. Иначе текст возвращается, запись
попадает в `fit` с причиной:

- `moved card` — карточка выросла: текст длиннее, чем она вмещает;
- `moved <слой>` — сдвинулись соседние слои;
- `overflow` — текст вылез за карточку.

Для `fit` подобрать короче — официальное короткое название, без подзаголовка — и записать снова; не влезает — в отчёт.
`sample` — по одной карточке каждого сета: снять скриншот экрана до записи и после.

Проверено: короткое название встало в 37 из 37 заглушек без сдвигов; длинное (больше строки) — откачено во всех 37
(`moved card`), исходный текст вернулся.

# Аудит: из каких библиотек компоненты на странице (2026-10-31, ЯПС «Общий Поиск»)

Правило владельца: в чистовиках всё **либо локальное, либо из ДС Платформа** (иконки, нейплейты, картинки — Графика,
оформление страниц — Органайзер). Компоненты из черновиков и чужих библиотек — брак.

## Как проверять

1. На странице собрать ключи наборов (`setOf(main).key`) всех инстансов, отдельно верхние и вложенные.
2. Классифицировать ключ **по файлу-источнику**: в ДС Платформа, Графике, Органайзере пройти `findAllWithCriteria
   COMPONENT/COMPONENT_SET` и найти совпадения ключей (локальный компонент файла = его ключ). Что не нашлось ни в одном —
   чужое. Имя не в счёт; `search_design_system` ключей проектов не показывает.
3. Чужое на верхнем уровне — двойник в ДС по смыслу и вариантам (пример: «action bar» из черновика = `mini-player`
   ДС с теми же State; введённый запрос — вложенный `. / mini-player / search` `state=typing` + текст `Query`),
   сравнение картинкой; нет двойника — отвязать в локальное. Скрытое чужое — отвязать (вид не меняется).
4. После свапа у вложенных инстансов ДС не оставлять переопределения подписей (свап переносит старый текст в чужое поле):
   `resetOverrides()` вложенного и выставить только нужные свойства. **Подписи в компонентах ДС не правим** (владелец).
5. Чужое внутри мастеров ДС (вложенное через компонент ДС) — хвост ДС, в отчёт; без «да» в ДС не трогать.

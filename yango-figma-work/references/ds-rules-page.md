## Тексты

Как у соседей — **без текстовых стилей**, одной гарнитурой: **Yango Text Medium 26/34, letter spacing 0**. Regular и
другие кегли запрещены (владелец, 2026-11-03).
- Цвет — переменные Theme диапазонами в одном тексте: ключевое слово (термин, платформа, место применения) — `Fill/One`,
  пояснение — `Fill/Subtitle` (`setRangeFills` с краской через `setBoundVariableForPaint`). Вводная строка («Где
  применяем:») — без списка, `Fill/Subtitle`.
- Списки — `setRangeListOptions(s, e, { type: 'UNORDERED' })` + `setRangeIndentation(s, e, 1)`.
- Тексты в клоне старые: «YS Text Display Regular» — это family `YS Text`, style `Display Regular`. Загрузить именно его
  (`loadFontAsync({ family: 'YS Text', style: 'Display Regular' })`), иначе запись падает; потом `fontName` → Yango Text
  Medium.
- Проверки ядра (`06-text-styles.js`) покажут эти тексты «без стиля», а 26 — вне шкалы. На страницах правил так и надо, как
  у соседей: к стилям не привязывать. Проверять семейство, начертание, кегль, интерлиньяж, трекинг и цвета на переменных.

## Таблица

```
table (F)        V, gap 20, pad 32, радиус 12, FILL × HUG; заливка — копия fills с 7529:2173 (#212121, без переменной)
├─ head (F)      H, gap 24, FILL × HUG; тексты — Fill/Subtitle
├─ divider       Type=Edge-to-Edge (сет 7529:5850), FILL × 1
├─ <строка> (F)  H, gap 24, FILL × HUG; тексты — Fill/One; имя = текст первой ячейки
├─ divider
└─ …             после последней строки дивайдера нет
```

- Дивайдеры — инстансы `divider` `Type=Edge-to-Edge`, ширина FILL; между шапкой и строками и между строками.
- Колонки: крайние — FIXED по самому длинному тексту колонки (у хаптиков 287 и 269), средняя — FILL, переносы в ней.
- **Ширину мерить временным текстом вне авто-лейаута**: текст прямо на странице, `textAutoResize = 'WIDTH_AND_HEIGHT'`,
  тот же шрифт → снять `width` → удалить. Внутри авто-лейаута у FILL / FIXED текста настоящей ширины не узнать.

## Примеры

**Не скриншоты, а инстансы ДС для ЯПС** (владелец, 2026-11-03).

```
img (F)               H, wrap, gap 24 / 32 (в ряду / между рядами), paddingTop 24, FILL × HUG; Product = YaPS
└─ <Подпись> (F)      V, gap 12, ширина 375 FIXED × HUG; имя = подпись
    ├─ preview (F)    H, gap 12, 375 FIXED × HUG, заливка Theme Surface/One (чёрный); Product = YaPS
    │   └─ инстанс(ы) ДС
    └─ label (T)      подпись, FILL × HUG
```

- Режим: библиотечная коллекция `Product` — Yango Play / YaPS / Allplay; для примеров — `YaPS`,
  `setExplicitVariableModeForCollection` на `img` и на каждом `preview`.
- Отступы `preview`: 16 со всех сторон — у отдельных контролов (кнопки, тост, контролы плеера); 16 сверху и снизу, 0 по
  бокам — у компонентов шириной 375 (мини-плеер, шапка плейлиста, меню, чипсы); таймлайн — 16 / 24.
- Подпись — короткое имя элемента («Мини-плеер», «Тост», «Таймлайн»), как у `8930:504`: Yango Text Medium 26/34,
  `Fill/Subtitle`, без стиля, FILL × HUG.
- Скриншот — только если в ДС нет компонента (у хаптиков — каверы в плеере `8930:527`, прогресс загрузки `8930:547`):
  картинка 375 внутри того же чёрного `preview` (pad 0, gap 0).
- Навбар и таббар в образце (`8930:501`) — без `preview` и без режима на `img`, бренд — вариантом `App=YaPS`.

Иконки в кнопках — из 🦄 Графика: `importComponentSetByKeyAsync(ключ)` → вариант `Size=24` → `swapComponent` на
вложенной иконке.

## Грабли

- `list-item / music`, свойство `add button` — это плитка «+» **вместо обложки** (строка «создать»), а не плюс справа.
- Подписи `Fill/Subtitle` (белый 50%) не видны на скриншоте галереи `img`: у неё прозрачный фон. Снимать секцию
  `by-the-author` целиком.

# Экран по скриншоту приложения (мобилка + планшет)

Первая задача 2026-10-29: витрина «Каналы» Кинопоиска в ЯПС · Current State
(`uBatydFjyjVhDM8AZqG5gC`, секция `Channels` 18793:272479): мобилка 375 × 812 и планшет 1024 × 768.

## Порядок

1. **Образец.** Тот же экран в другом продукте почти всегда уже собран: каналы — Movies 📺 Live TV
   (`S1qr8Qh4kjEmyQb5NnXlat`, 4574:21268), шапка витрины — соседний экран того же раздела (Кинопоиск «Витрина Кино»).
   Берём из образца состав компонентов, не копируем слои.
2. **Каркас экрана** (как у соседей в файле):
   - `screen` — фрейм FIXED, вертикальный auto-layout, обрезка, заливка — та же переменная, что у соседних экранов;
   - `content` — поток, `paddingTop` = высота шапки, внутри строки ДС (FILL по ширине);
   - `header` — ABSOLUTE, STRETCH / MIN: `Fade` (ABSOLUTE, перевёрнут `[[1,0,0],[0,-1,210]]`, `Scroll Contrast`,
     `Tab level=on`, если под навигацией ряд чипсов) → `status-bar / ios` без заливки → `Top Navigation` → `chips-row`;
   - `bottom bar` — ABSOLUTE, STRETCH / MAX, gap 8, `itemReverseZIndex`: `mini-player` (скрыт, если на скриншоте его
     нет) → `Tabbar`.
3. **Планшет 1024.** Ширина 1024 — iPad в ландшафте, высота 768. `status-bar / ios` `device=ipad` (24),
   `Top Navigation` `Platform=tablet`, `Tabbar` `Platform=iPad` (74), `chips-row` FILL. Строки списка 375-го дизайна на
   1024 — две колонки (`content` горизонтальный, две `column` FILL): внутренние отступы строки 16 совпадают с краями
   навигации. Порядок — по колонкам, чтобы последний ряд под таббаром был тем же, что на телефоне.
4. **Контент** — только то, что видно на скриншоте: подписи, возраст, «ещё N мин», доля прогресса (замер по пикселям).
   Чего не видно (закрыто таббаром) — условное значение, в отчёте назвать.

## Активные состояния

- Активный таб верхней навигации — `State` вложенных `. / top navigation / tabs` (как на экране «Спорт»), не своё.
- Активный чипс — `Active=on <бренд>` первого `chip` (`on YaPS` для ЯПС, `on Yango Play` для Yango Play).

## Картинки со скриншота (логотипы, обложки)

- Вырезать из скриншота дизайнера (PIL, круг — по крайним светлым пикселям, вставка −2 % по краю), PNG 160 × 160.
  Закрытое чужим слоем (иконка таббара поверх логотипа) — не брать, оставить заглушку ДС.
- `upload_assets` без `nodeIds` (у слоёв внутри инстансов id вида `I…;…` не принимаются) → кадры с картинкой на
  странице, в ответе `imageHash` → заливка слоя `image` внутри обложки: стопка мастера + картинка сверху
  (`[...main.fills, {type: 'IMAGE', imageHash, scaleMode: 'FILL'}]`) → временные кадры удалить после проверки, что хеши
  сидят на новых носителях.

## Грабли

- `card / progress-bar / bar`: `resize` прямоугольника `item` в инстансе молча не применяется. Доля прогресса —
  `item.layoutSizingHorizontal = 'FILL'` + `bar.paddingRight = bar.width − доля`.
- `list-item / media` `Type=tv-channel`: подпись канала (`caption`) была FIXED 188 и переносилась на вторую строку —
  длинные названия («Детско-юношеский телеканал "Карусель"») делали строку 118 вместо 110. Исправлено в ДС 2026-10-29
  (владелец: «одна строка до обрезки»): атом `text-label / caption` 7529:8108 — текст `ENDING`, `maxLines = 1`;
  `text-label` 7529:7990 — `caption` на всю ширину (STRETCH). До публикации ДС в экранах — `caption` FILL переопределением.
- `description` строки показывает «Age • Description»: для одного возраста скрыть `divider dot` и второй `label`; нет
  возраста — булево `Description` у `text-label` выключить.
- В самом файле ДС `importComponentSetByKeyAsync` каждый раз отдаёт новую удалённую копию (другие id) — там читать
  локальные узлы по id, импорт — только в проекте.
- Подпись экрана с `opacity = 0` (вторая `paragraph` в ряду) — намеренная распорка, текст не менять.

## Правка атома ДС по ходу сборки

- Сначала перепись: где слой реально виден. `getInstancesAsync()` у каждого варианта атома / носителя → владелец
  (ближайший мастер) и включено ли булево (`Caption#…`) с видимостью по цепочке. Подпись `caption` видна только в строках
  каналов (новый `list-item / media` и ❌-набор), в остальных 45 носителях скрыта — правка в атоме безопасна.
- «Было → стало» — на временных инстансах рядом с набором (LTR и RTL, длинный текст), снимки, потом удалить.
- Получатель свойства: у ребёнка-инстанса с FIXED по главной оси геттер `layoutSizingHorizontal` после `FILL` может
  отдавать FIXED, хотя `layoutAlign = STRETCH` и в инстансах ширина тянется — проверять шириной на временном инстансе.
- После правки — `getPublishStatusAsync()` = `CHANGED` у атома, носителя и строки: просить публикацию ДС, затем «Update all».

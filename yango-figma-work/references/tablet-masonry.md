# Масонри-сетка на планшете 1024 (ЯПС «Общий Поиск», 2026-11-03)

Задача: экран поисковой выдачи «Всё» (`19151:19605`, 375, 3 колонки по 109) → планшет 1024 × 768 рядом в том же ряду
секции (`19362:8701`).

## Колонки

Правило владельца: поля экрана и зазоры между колонками постоянные (16 / 8), растёт только ширина колонок и карточек.
Ширина колонки = (1024 − 2 × 16 − 8 × (n − 1)) / n: 5 → 192, **6 → 158,67**, 7 → 135, 8 → 117. Взято 6: ширина совпадает
со средним размером карточек ДС (`card / album` / `card / artist` / `card / playlist` / аудиокнига `Size=medium` — 159),
у 8 колонок — почти телефонные 109. Колонки — `FILL` в сетке шириной 992, карточки — `FILL` в колонке; размеры карточек
(small) не меняем — только ширина.

## Состояние

На 1024 × 768 клавиатура iPad (428) оставляет один неполный ряд — планшет показан в просмотре выдачи без клавиатуры
(решение владельца): `mini-player` `State=focus` растянут на 1024 над `home-indicator / ios` `ipad=true, landscape=true`
(20, ширину подогнать до 1024), с перекрытием 2, как на телефоне. `status-bar / ios` `device=ipad`, `Top Navigation`
того же типа с `Platform=tablet` (`swapComponent` переносит тексты и активный таб).

## Наполнение

Шести колонкам нужно ~18–20 карточек при 13 на телефоне. Недостающие — копии карточек того же типа из этой же сетки с
картинкой и подписями из строк соседних экранов (табы «Музыка», «Кино», «Книги»): `imageHash` — с обложки строки,
подписи — по таблице типов PRD. Раскладка — порядок чтения телефона (по `y`, затем по колонке) и «в самую короткую
колонку»; высоты читать после `FILL`. Сверять с телефоном, чтобы не задвоить сущность (Тарантино уже был на телефоне).

## Грабли

- `card / book` внутри фрейма `book` не тянется за `FILL` карточки — остаётся 109. Высота по пропорции книги:
  `resize(w, w × h0 / w0)`, потом `FILL`. Постеры и квадратные обложки растягиваются сами.
- Ряд экранов секции был `FIXED`, а первый экран в нём — `FILL`: переключение ряда на `HUG` схлопнуло его до 32.
  Перед сменой сайзинга ряда — перевести такие экраны в `FIXED` с их шириной.
- Подпись, скрытая на телефоне клавиатурой, на планшете видна — ошибки исходника (постер «Амели» с подписью
  «Идеальные дни») всплывают; править в планшетной копии и назвать в отчёте.
